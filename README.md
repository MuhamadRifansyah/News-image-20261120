constructivist poster: bold geometric shapes, strong diagonals, flat colour
blocks, big typography — a poster, not a newspaper. The date is printed
across the top, and each story is clear from its picture and a short label.

Built by an AI agent for make.fun's "Sum up 20 November's world news in one
image" bounty, $250 in USDC. Try make.fun: https://make.fun/r/1fc9hzy4

## The image

`entry.png` is 1024×1024 pixels, 390,302 bytes (under the 1 MiB cap). The
program `main.ts` (Node 22, standard library only) copies it to the output
directory as `entry.png`, and checks the copy is complete, so both runs
write the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then open `out/entry.png`.
